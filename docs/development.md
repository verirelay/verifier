# Development

## Checks

```sh
go run mvdan.cc/gofumpt@v0.12.0 -w .
go vet ./...
go test ./...
make build
golangci-lint run
actionlint
```

CI uses golangci-lint v2.15.0 and actionlint v1.7.12.

The web interface is the embedded `internal/webui/index.html`.

| Target | Action |
| --- | --- |
| `make build` | Build `dist/verifier` |
| `make check` | Run tests, build and lint |
| `make release VERSION=<tag>` | Cross-compile the release binaries and `SHA256SUMS` into `dist/release` |

Pushing a `v*` tag starts the release workflow, which:

1. runs `make release`;
2. attests every asset in `dist/release` with GitHub artifact attestation;
3. publishes a GitHub Release.

## Package API

`pkg/verifier` runs the same verification as the CLI from Go. See the [package documentation](https://pkg.go.dev/github.com/verirelay/verifier/pkg/verifier).

## Tests

Fixtures under `internal/testdata` are synthetic evidence generated by VeriRelay. [internal/testdata/README.md](../internal/testdata/README.md) lists them and explains how to regenerate them.

The CLI pass golden is printed from the report golden. To update the report and CLI goldens after review, run these in order:

```sh
UPDATE_GOLDEN=1 go test ./pkg/verifier
UPDATE_GOLDEN=1 go test ./internal/cli
```
